# 作品集 · 国内接单起步包

> 借助 DSH 准备的国内接单起步素材。含 2 个可演示作品 + 接单简历模板 + 话术书 + 避坑清单。

## 目录结构

```
portfolio/
├── toolbox/            # 作品一：在线工具箱（纯前端网页，单文件）
│   └── index.html
├── scraper/            # 作品二：网页数据抓取工具（Python，零依赖）
│   ├── scraper.py
│   └── README.md
├── 接单简历模板.md      # 码市/猪八戒等平台的个人主页填写模板
├── 接单话术书.md        # 报价、沟通、破零话术（低门槛低报酬起步）
├── 接单避坑清单.md      # 442 分段收费、坑单识别、起步 5 步流程
└── README.md           # 本文件
```

## 两个作品

| 作品 | 类型 | 亮点 |
|---|---|---|
| 在线工具箱 | 前端网页 | 5 个实用工具，零依赖、单文件、离线可用 |
| 网页抓取工具 | Python 脚本 | 零依赖、自动解析、导出 CSV/JSON，实测可用 |

## 部署到 GitHub Pages

作品一（toolbox）可部署为在线链接，客户点开即看。步骤见下方（需 GitHub 账号）。

```bash
# 本地预览
cd /root/dsh/portfolio/toolbox && python3 -m http.server 8099
```

## 起步路线（速览）

1. 注册码市（首选，不查学历）+ 猪八戒/一品威客
2. 用「接单简历模板.md」完善主页，上传作品截图
3. 按「接单话术书.md」报价，按「接单避坑清单.md」避坑
4. 从低价小单破零攒好评，逐步提价
